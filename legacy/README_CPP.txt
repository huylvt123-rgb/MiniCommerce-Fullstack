C++17 SOURCE DEMO FOR LABS 1-7

Mac / Linux: open Terminal in this folder and run: bash run.sh
Windows: install MinGW-w64 g++ and add it to PATH, then double-click run.bat
Manual build: g++ -std=c++17 -O2 SevenLabs.cpp -o sevenlabs

IMPORTANT: C++ source code requires compilation before it runs. run.sh / run.bat AUTOMATICALLY COMPILE and launch the program. This is a console program, separate from the offline HTML/JS demonstration. The HTML website does not invoke the C++ executable.

Menu: Lab1 array benchmark; linked-list inventory; cart/stack undo; FIFO orders; BST; 5 sorts; sequential/binary/hash search; 100k benchmark; integration tests; generate data.

NOTE: Test data and payments are simulations. This project is a teaching demonstration, not a production commerce backend. BubbleSort 100k is optional because it can take a long time.
